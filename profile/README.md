## 🚀 Projects

### [Streamyfin](https://github.com/streamyfin/streamyfin)
<a href="https://github.com/streamyfin/streamyfin/releases"><img alt="Release" src="https://img.shields.io/github/v/release/streamyfin/streamyfin?style=flat-square"></a>

A Jellyfin client built with Expo for seamless media streaming across iOS, tvOS, and Android.

### [Streamyfin Jellyfin Plugin](https://github.com/streamyfin/jellyfin-plugin-streamyfin)
<a href="https://github.com/streamyfin/jellyfin-plugin-streamyfin/releases"><img alt="Release" src="https://img.shields.io/github/v/release/streamyfin/jellyfin-plugin-streamyfin?style=flat-square"></a>

Server-side plugin that integrates directly with Streamyfin, providing centralized configuration, push notifications, and expanded functionality.

### [Streamyfin Discord Bot](https://github.com/streamyfin/streamyfin-discord-bot)
Streamlines project management in Discord by syncing issues, feedback, and more with the GitHub ecosystem.

### [Streamyfin Website](https://github.com/streamyfin/streamyfinweb)
The official Streamyfin website, providing updates, documentation, and project overviews.
